# Brand logos for the switch lab

Drop a logo here named after the brand in lowercase, e.g. `cherry.svg`, `gateron.png`, `kailh.svg`,
`akko.svg`, `durock.svg`, `zeal.svg`, `drop.svg`, `outemu.svg`. SVG or PNG, ideally a wide wordmark
on a transparent background. Brands without a file show their name as a text wordmark.

## Sources

Brand logos are trademarks of their owners, used here only to label their own switches. Fetched from each brand's
official website on 2026-10-10: cherry.de, gateron.com (its image host ueeshop.ly200-cdn.com), kailhswitch.com,
en.akkogear.com, zealpc.net, drop.com (assets.corsair.com). Durock (durock.co is a parked domain) and Outemu
(outemu.com was down) have no file and show a text wordmark.
